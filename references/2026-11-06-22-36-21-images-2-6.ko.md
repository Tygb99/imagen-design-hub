# Images 2.6 옵션

[English](2026-11-06-22-36-21-images-2-6.md)

2026-11-06 KST 확인: [공식 발표](https://openai.com/index/introducing-images-2-6/), [API 가이드](https://developers.openai.com/api/docs/guides/image-generation), [프롬프트 가이드](https://developers.openai.com/api/docs/guides/image-prompting).

네이티브 PNG·JPG 생성과 편집은 설치된 imagegen 스킬과 현재 도구 명세를 따르고 노출된 인자만 전달한다. 도구가 제공된다는 이유로 백엔드 모델이나 모든 API 기능을 단정하지 않는다. Free 미지원 진단을 유지하며 “모든 구독 등급”을 Free 지원의 근거로 해석하지 않는다. GIF는 sprite-gen으로 제작한다.

## 사용자가 명시적으로 선택한 API 작업

사용자가 선택한 API 도구·클라이언트가 아래 옵션을 실제 지원할 때 사용한다. 플러그인은 지침을 제공하며 API 클라이언트를 추가하지 않는다. 실제 호출 전에 공식 문서를 다시 확인한다.

| 옵션 | 사용 |
| --- | --- |
| `model` | 빠른 반복은 `gpt-image-2.6-flare`, 세부 묘사·정밀 편집은 `gpt-image-2.6-sunburst`부터 실제 작업으로 비교한다. |
| `quality` | `auto`·`low`·`medium`·`high`·`xhigh`·`max`. 디테일과 충실도를 제어한다. 최종 소재는 높은 설정과 비교한다. |
| `complexity` | `low`·`medium`·`high`, 생략 시 `high`. 국소 수정은 `low`, 복잡한 구성은 높은 설정을 시험한다. 비교할 때 quality를 고정한다. |
| `background` | 투명 래스터 출력은 PNG 또는 WebP에 `transparent`를 지정하고 디코딩한 알파를 확인한다. |

수정 위치 지정은 `/v1/images/edits`를 사용한다. 첫 입력은 원본이며 `markup`은 방향을 반영한 원본과 같은 크기의 별도 투명 PNG 표시 레이어다. 변경할 부분과 유지할 부분을 설명한다. `mask`·`prompt_rewriter`와 함께 쓰지 않는다. 결과에 표시가 남지 않았는지 확인한다.

SVG는 `/v1/images/generations`에서 `output_format="svg"`·`n=1`을 사용하고 반환된 base64를 UTF-8 SVG로 저장한다. 편집 엔드포인트의 SVG 출력과 streaming·partial images·`output_compression`·`prompt_rewriter`는 지원하지 않는다. 원본을 보존한 뒤 [SVG 후처리·검증](../skills/svg/SKILL.ko.md)을 적용한다.

## 편집·시리즈 검수

편집 전에 대상을 확인한다. 변형은 검수한 기준 이미지를 재사용하고 변경할 부분을 지정하며 별도 요청이 없으면 정체성·형태·팔레트·구도·알파를 유지한다. 각 수정본을 원본과 비교하고 최종 시리즈도 함께 본다. 프롬프트·참조 이미지·반환된 모델 근거·실제 파일 측정값을 기록한다. 모델 품질·크기 옵션은 DesignHub 접수나 프로젝트 DPI 목표를 대신하지 않는다.
