# SVG 스킬 정식 전환 검수 — 0.9.0

[English](2026-11-06-22-47-15-svg-qualification.md) · [측정 근거](2026-11-06-22-47-15-svg-qualification.json)

**로컬 SVG 제작·편집·메타데이터 준비 범위 PASS.** Images 2.6 API SVG 생성과 실제 DesignHub 업로드·등록·심사는 실행하지 않았다. 정식 스킬 이름은 `imagen-design-hub:svg`다.

## 대상과 계약

- 스킬 루트: 새 배포 폴더 안의 `plugin/skills/svg/`.
- 배포 포함 파일: `package.json`의 `files` 항목만 독립 폴더 두 곳에 복사했다. Git 이력·원본 작업 폴더·이전 실행 산출물은 사용하지 않았다. SVG·공통·키워드·업로드 지침은 배포물 안에 있다.
- 대표 요청: 줄기·잎이 있는 단순 꽃, 제공된 테두리 원형 배지, 빈 말풍선을 제작하고 원본과 한국어 메타데이터를 준비한다.
- 입력: `input/round-badge.svg`. 1024×1024 캔버스, 중심 (512,512), 반지름 400, 흰 채움, 두께 48의 짙은 테두리를 가진 원이다.
- 탐색 경계: `input/`, 깊이 1, `*.svg`, 파일명 오름차순, 심링크 미추적. 다른 입력 루트는 제외한다.
- 기대 산출물: `output/`의 SVG 3개, `sources/`, `preupload.csv`, `result.json`, `missing-input.json`.
- 허용 변동: 새 꽃·말풍선의 도형·색, 20~25개 범위의 검색어 표현·개수, 실행 경로·시각. 입력 선택·경로·처리 순서·출력 구조·최종 판정은 같아야 한다.
- PASS 조건: 실제 벡터, 5색 이하, stroke 속성 없음, 테두리 보존, 잘림 없는 타이트한 경계, 최대 6000px, 150000바이트 미만, 정확한 6열·BOM 없는 UTF-8 CSV, 빈 ID, 올바른 콘텐츠 타입.

잘못된 XML, 래스터 삽입, 스크립트, foreignObject, 외부 링크, stroke=none, 6색, 6000px 초과, 파일 용량 초과, viewBox 누락, 외부 엔티티의 11종을 모두 거부했다. 검사기는 그룹의 fill 상속을 반영한다. 이 코드는 단순 벡터 인수 테스트용이며 전체 SVG 명세 검증기는 아니다.

## 발견한 결함과 수정

| 결함 | 재현 증거 | 수정 | 재검증 |
