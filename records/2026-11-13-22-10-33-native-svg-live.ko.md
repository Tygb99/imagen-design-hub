# 내장 이미지 생성과 DesignHub SVG 승인 검증 — 0.9.0

[English](2026-11-13-22-10-33-native-svg-live.md) · [측정 기록](2026-11-13-22-10-33-native-svg-live.json)

**2026-11-13 KST, DesignHub 승인 확인.** 내장 image_gen으로 생성한 튤립을 실제 SVG 경로로 변환해 2026-11-06에 업로드하고 심사에 제출했다. 사용자가 제공한 DesignHub 화면에서 같은 SVG가 승인된 것을 확인했다.

## 생성과 벡터 검사

- 도구는 내장 `image_gen`이며 출력은 PNG다. 정확한 모델·버전·Flare·Sunburst 식별값은 반환하지 않았다. 이번 검증은 내장 PNG → 벡터 경로이며 직접 SVG 생성이나 Images 2.6 API 호출의 검증이 아니다.
- 주제는 초록 잎과 노란 리본이 있는 분홍 튤립이다. PNG 후보 3개와 변환 원본을 보존했고 최종 벡터는 후보 3을 사용했다.
- 앞선 투명 후보에는 부드러운 음영·알파 테두리가 있었다. 팔레트 제한 없는 최초 변환은 색상 수를 초과해 업로드하지 않았다. 흰 배경의 평평한 이미지를 새로 생성한 뒤 로컬에 준비한 VTracer `1.0.0-alpha.4`의 고정 팔레트로 변환했다. 분리된 흰 배경 경로를 제거하고 전체 가시 경계에 viewBox를 맞췄다.
- 최종 SVG는 `native-coral-tulip-ribbon-20261106232641.svg`다. 3,720바이트, 761 × 1262.13 단위, 가시 색상 4개, 경로 6개이며 stroke 속성·래스터 삽입·스크립트·외부 링크·foreignObject가 없다. SHA-256: `7cd825e35f5f7aae82bf24e852f37202c7f1a524a03705a56cbbaa19b0cf188a`.
- 최종 벡터 렌더링을 시각 검수했다. 내장 생성은 원격 도구가 수행하며 로컬 하드웨어 선택을 노출하지 않는다. 로컬 VTracer·XML 후처리는 CPU를 사용했고 테스트한 CLI에는 GPU 실행 옵션이 없다.

실사용 산출물 폴더 기준 변환 명령은 다음과 같다.

```sh
tools/vtracer assets/source-imagegen/tulip-native-v3.png assets/source-svg/tulip-v3-traced-original.svg \
  --palette '#E57983,#F5B6AE,#4B8062,#F2CE70,#FFFFFF' \
  --hierarchical cutout --filter-speckle 64 --simplify 2 --path-precision 2 --optimize 2
```
