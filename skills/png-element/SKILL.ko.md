# PNG 요소

[English](SKILL.md)

[공통 규칙](../../SKILL.ko.md)을 읽는다. 추천에는 주제·스타일·사용처·구매자 검색어를 담은 콘셉트 3~5개를 제시한다.

1. 설치된 imagegen 스킬에 따라 내장 image_gen으로 실제 투명 배경을 명시하고 요소 하나당 한 번 생성한다.
2. 원본은 assets/source-imagegen/에 보존한다. 자식 세션·브라우저·API 키·크로마키·배경 제거를 필수화하지 않는다.
3. 완전 투명 외부 픽셀, 비어 있지 않은 피사체, 의도된 부분 알파를 확인한다. 그려진 체크보드는 실패이며 자동 키잉 대신 재생성한다.
4. Pillow 또는 프로젝트 처리기로 별도 복사본의 트림·크기·DPI·용량을 맞춘다. 필요한 수동 편집이나 명시적 요청에만 Photopea를 쓴다.
5. 체크보드·흰색·어두운 배경에서 내부 구멍·테두리·잘림을 검사한다. 보라색·초록색·낮은 알파를 일괄 제거하지 않는다.
6. 고유 파일명과 구매자 검색어 20~25개의 PNG element CSV를 만든다. 승인된 업로드는 [upload-csv](../upload-csv/SKILL.ko.md)를 따른다.

유리·반투명 효과의 부분 알파를 보존하며 GIF 크로마 제거를 적용하지 않는다. 네이티브 출력이 반복 실패하면 알리고 요청 범위에서 대안을 선택한다.
