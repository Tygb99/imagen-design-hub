# JPG 배경

[English](SKILL.md)

`jpg배경`, DesignHub 배경 JPG, 문서용 그래픽 배경, 반복 패턴 요청에 사용한다. 확장자를 정하기 전에 실제 내용으로 타입을 판단한다. JPG라는 이유만으로 Background에 해당하지 않는다. 공통 절차는 [../../SKILL.ko.md](../../SKILL.ko.md)를 따른다.

## 심사 적합성

2026-10-02 KST에 공식 [배경 가이드](https://slashpage.com/designhub-guide/ndvwx728377exm3z6jpg)와 [사진 타입 상세](https://slashpage.com/designhub-guide/5r398nmnrxxd3mvwje7y)를 확인했다. 제출 시 기준이 바뀌었을 가능성이 있으면 다시 확인한다.

| 실제 내용 | 처리 |
| --- | --- |
| 인물·동물·사물이 피사체로 존재하지 않는 그래픽 일러스트 | `Background`. 추상 곡선·점·그래픽 종이 질감 등이 해당한다. |
| 특정 피사체가 돋보이지 않는 조화로운 패턴 | `Background`. 알아볼 수 있는 반복 무늬를 일괄 금지하지 않고 균형과 시각적 강조를 확인한다. |
| 실사 또는 실사에 매우 가까운 이미지·풍경 | 해당 타입 기준에 따라 `Photo`로 구분한다. 수면·수영장 바닥·종이·빛 반사도 자동으로 배경이 되지 않는다. |
| 특정 인물·동물·사물이 중심인 사각형 일러스트 | 단일 객체로 분리해 알맞은 요소 타입으로 제출한다. 분리할 수 없으면 지원되지 않는 유형이며 `Photo`로 바꿔 제출하지 않는다. |

학교 안내문·공지·포스터를 여러 형식으로 요청받아도 JPG는 별도 그래픽 배경 레이어로 제작한다. 다른 형식에 글자가 허용되어도 JPG 배경에는 안내 문구와 중심 일러스트를 넣지 않는다. 완성된 안내 레이아웃을 JPG로 저장하는 것으로 배경 적합성이 해결되지 않는다.

## 생성·파일 검사

1. 내장 `image_gen`으로 불투명한 사각형 그래픽 배경 또는 조화로운 패턴을 화면 전체에 생성한다. 오려낸 요소나 크로마키를 요청하지 않는다. 문서용 배경에는 안내 문구·로고·워터마크·UI 캡처·장식 프레임을 넣지 않는다.
2. 현재 run에 원본 PNG와 직접 작성한 프롬프트를 보존한다. 사본을 RGB `.jpg`로 변환하며 원본·실패 후보를 덮어쓰지 않는다.
3. 실제 JPEG 시그니처·RGB 모드·크기·DPI·용량과 시각적 타입 적합성을 확인한다. 파일 검사 통과만으로 콘텐츠 타입 적합성이나 심사 승인을 단정하지 않는다.

공식 [파일 규격](https://slashpage.com/designhub-guide/3p4kj92ynppxkm57q1x8)의 배경 기준은 JPG·최소 120 DPI·2500~9800px·최대 50MB다. 로컬 준비 목표는 각 변 2500~9800px·50MB 미만·300 DPI이며 프로젝트 지시를 우선한다. 프로젝트가 350 DPI를 요구한다면 이를 따르되 공식 최솟값과 구분한다. 크기 조정 시 비율을 유지한다.

## 메타데이터·제출

- CSV는 `fileName,uniqueId,elementName,keywords,tier,contentType`을 쓴다. 업로드 전에는 확장자 없는 JPG 파일명과 빈 `uniqueId`, 기본 `Premium`을 사용하며 적합한 배경에만 `Background`를 지정한다.
- 실제 그래픽·패턴을 설명하는 중복 없는 구매자 검색어 20~25개를 쓴다. 기말고사 묶음에서 만들었다는 이유로 추상 배경을 완성된 안내문처럼 이름 붙이지 않는다.
- 로컬 업로드 전 Background 행은 적합한 JPG 후보 수와 대응해야 한다. 업로드 후 DesignHub CSV는 다른 형식을 포함한 모든 행·발급 ID·파일명 표기를 보존해 병합한다.
- 공식 [AI 가이드](https://slashpage.com/designhub-guide/7vgjr4m1nqq8k2dwpy86)에 따라 편집 여부와 관계없이 생성형 AI 표시를 확인하고 프롬프트·원본 증거를 보존한다.
- 승인된 업로드·심사 제출은 [upload-csv](../upload-csv/SKILL.ko.md)를 따른다. 기존 승인을 재요청하지 않는다. 파일 업로드·메타데이터 처리·심사 상태를 각각 확인하며 제출과 승인을 구분한다.
