# JPG 배경

[English](SKILL.md)

내장 image_gen으로 화면을 채우는 배경을 생성한다. 주요 피사체·문구·로고·테두리 없이 자연스러운 질감과 패턴을 만든다. 투명·크로마키·체크보드를 요청하지 않는다. 원본 PNG를 보존하고 RGB JPG로 변환한다.

학교 안내문·공지·포스터를 여러 형식으로 요청받아도 JPG는 별도의 피사체 없는 배경 레이어로 제작한다. PNG·GIF·SVG 요소에 글자를 넣어도 된다는 허용이 완성된 안내 포스터를 Background로 제출해도 된다는 뜻은 아니다. JPG로 확장자를 바꾸는 것만으로 콘텐츠 타입 부적합이 해결되지 않는다.

양변 최소 2500px, 최대 9800px, 최소 120 DPI(프로젝트 지시 없으면 300 DPI), 50MB 미만을 검증한다. CSV는 확장자 없는 fileName, contentType Background, 제공된 경우에만 uniqueId, 중복 없는 검색어 20~25개를 사용한다. 원본·실제 JPG·알파 없음·크기·용량·CSV 대응·전체 배경 적합성을 검사하고 승인된 범위에서만 외부 업로드한다.
