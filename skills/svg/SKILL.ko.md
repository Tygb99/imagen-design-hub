# SVG 요소

[English](SKILL.md)

## Images 2.6 생성·편집

선택한 도구의 실제 출력 형식을 확인한다. 실제 SVG 생성이 노출되면 해당 내보내기를 사용하고 반환 원본을 후처리 전에 보존한다. 사용자가 내장 `image_gen`을 선택했고 도구가 PNG를 반환하면 원본을 보존한 뒤 트레이싱하거나 다시 구성해 실제 벡터 경로로 변환한다. 기존 벡터·편집기 내보내기·단순 벡터 직접 작성도 사용할 수 있다. Images 2.6 API는 사용자가 해당 경로를 명시적으로 선택했을 때 사용한다. 내장 도구 인자를 지어내거나 유료 생성으로 자동 전환하지 않는다.

내장 PNG를 트레이싱할 때는 가시 색상 5개 이하의 단순하고 평평한 도형을 요청하고 VTracer 같은 사용 가능한 벡터 변환기·편집기를 사용한다. 그라데이션·알파 테두리·질감은 색상 초과나 잡티를 만들 수 있다. 피사체와 명확히 분리된 단색 배경은 변환 후 벡터 도형으로 제거할 수 있지만 피사체 자체의 흰 부분과 구멍은 보존한다. 팔레트를 의도적으로 제한하고 PNG와 벡터를 시각적으로 비교한 뒤 아래 윤곽선·경계·파일 검사를 적용한다. 근거에는 직접 SVG 생성이 아닌 내장 PNG 생성 후 벡터 변환이라고 기록하고, 도구가 식별한 경우에만 백엔드 모델을 명시한다.

선택한 API 경로는 `gpt-image-2.6-flare` 또는 `gpt-image-2.6-sunburst`, `/v1/images/generations`, `output_format="svg"`·`n=1`을 사용하고 반환 base64를 UTF-8 SVG로 저장한다. [옵션·API 제약](../../references/2026-11-06-22-36-21-images-2-6.ko.md)을 따른다. 생성된 SVG도 후보이므로 아래 후처리를 거친다. 기존 벡터 수정은 원본 형식에서 수행한다. 이미지 편집 엔드포인트는 SVG 출력을 지원하지 않는다. 래스터 미리보기를 참조로 사용하면 최종 벡터와 분리해 보존한다.

## 후처리·검증

실제 벡터 원본으로 단순한 요소를 제작한다. 래스터 확장자 변경이나 주요 그림의 비트맵 삽입은 금지한다. 채움색과 테두리색을 합친 가시 색상은 5개 이하로 유지한다. 흰색·검정은 포함하고 투명·none은 제외한다. 불필요한 배경·아트보드·영역 밖 도형을 제거한다. 스크립트·외부 링크·foreignObject·숨은 워터마크·폰트 잔여물을 넣지 않는다.

업로드 전에 모든 가시 테두리를 채움색이 있는 윤곽선 경로로 변환한다. 모양과 색을 유지하고 `stroke="none"`을 포함한 모든 `stroke`·`stroke-*` 속성을 제거했는지 확인한다. 실제 DesignHub 업로더는 Stroke 속성이 있는 SVG를 거부한다. 오류를 피하려고 가시 테두리를 없애지 않는다.

윤곽선 변환 후 벡터 편집기 또는 직접 작성한 도형의 기하 정보로 전체 가시 경계를 계산한다. 그 경계를 `viewBox`로 정하고 width·height의 비율을 맞춘다. 피사체 모양·색·테두리 두께를 보존하면서 원본 아트보드의 빈 여백을 자른다. 원본 캔버스 크기는 사용자가 그 크기를 명시적으로 요구할 때 유지한다. 가져오거나 편집한 SVG도 이 과정을 거치며, 피사체가 viewBox 안에 완전히 들어오고 빈 여백이 없는지 확인한다.

올바른 XML과 타이트한 viewBox, 최대 6000px, 0.15MB 미만을 검증한다. CSV는 확장자 없는 fileName, contentType SVG element, 제공된 경우에만 uniqueId, 중복 없는 검색어 20~25개를 사용한다. 승인된 범위에서만 외부 업로드하며 후보 품질과 실제 접수 상태를 구분한다.

CSV는 BOM 없는 UTF-8로 저장하고 헤더를 정확히 `fileName,uniqueId,elementName,keywords,tier,contentType`으로 맞춘다. 쉼표가 들어간 값은 따옴표로 감싼다. 업로드 없이 로컬 메타데이터만 준비할 때도 이 규칙을 적용한다.
